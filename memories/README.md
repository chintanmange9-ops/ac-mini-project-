# Memory Vault

Auto-written by the opencode memory-vault plugin.

- `preferences.md` - user preferences and working style
- `topics/<name>.md` - durable knowledge per topic (decisions, facts, patterns)
- `sessions/<date>.md` - daily activity traces (user requests, AI final answers)

Open this folder in Obsidian (File > Open folder as vault) to browse with graph view, backlinks, and full-text search.
